What is running here

Two trained Histogram Gradient Boosting models use the same historical feature row. Our model also receives writable-account history. Estimates are calibrated using validation data; the actual outcome is kept separate until you reveal it.

Research scope

This is genuine model inference on features reconstructed for a historical test transaction, not a live risk prediction for an arbitrary new transaction. The models were trained on an earlier day. The test outcome is not an input. Earlier test outcomes can enter history after the stated one-hour delay.

This comparison uses the original history models and the separate calibration follow-up, not the paper’s identity-controlled endpoint. Its warning thresholds can produce false alarms or miss failures. It has not demonstrated fee savings.
